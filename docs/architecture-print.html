Módulos del Sistema

Refugio

Mascotas, refugios, razas, procedencias, comportamientos. Soporte para fotos con ImageSharp.

Adopciones

Solicitudes de adopción, adopciones aprobadas, voluntarios y eventos.

Médico

Historial médico, citas veterinarias, vacunas, recetas y tratamientos.

Inventario

Categorías, items, recepciones de mercancía y detalles de entrada.

Empleados

Empleados, cargos y gestión de personas.

Catálogos Médicos

Gravedades, tipos de esterilización, medicamento, parásito y vías de administración.

General

Departamentos y municipios de Honduras.

Seguridad

Usuarios, registro de eventos y Cookie Authentication.

Flujo de Datos y Base de Datos

Request (Ida)

Browser HTTP → Controller (ViewModel) → Service (AutoMapper → Entity) → Repository (DynamicParameters) → SP

Response (Vuelta)

SQL Server (Result Set) → Repository (Dapper → SP Result) → Service (AutoMapper → ViewModel) → View() o Json()

Schemas de Base de Datos

Refugio — Mascotas, Adopciones Medico — Historial, Citas Inventario — Items, Entradas General — Departamentos Seguridad — Usuarios, Eventos dbo — Stored Procedures

Convención de Stored Procedures

PR_[Schema]_[Tabla]_[Operación]
PR_Refugio_Mascotas_List | _Find | _Detail | _Insert | _Update | _Delete
