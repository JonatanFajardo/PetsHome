# 📋 ¿DÓNDE SE USAN LOS CATÁLOGOS MÉDICOS?

## 🎯 RESUMEN RÁPIDO

Los 6 catálogos médicos que acabamos de crear se utilizarán en las siguientes pantallas/módulos del sistema:

---

## 🏥 1. TIPOS DE CONSULTA
**`tbTiposConsulta`** - Tipo de consulta médica realizada

### 📍 Pantallas que lo usan:

#### ✅ **CITAS MÉDICAS** (tbCitaMedica)
- **Pantalla:** Módulo de Citas Médicas / Agenda Veterinaria
- **Campo sugerido:** `tipoCon_Id` (FK a tbTiposConsulta)
- **Uso:** Al registrar una cita, el veterinario selecciona el tipo:
  - Consulta General
  - Emergencia
  - Control de Vacunación
  - Control Post-operatorio
  - Chequeo de Rutina

**Ejemplo de uso en formulario:**
```
┌─────────────────────────────────────┐
│ Nueva Cita Médica                   │
├─────────────────────────────────────┤
│ Mascota: [Max ▼]                    │
│ Fecha: [01/11/2025 10:00]           │
│ Tipo de Consulta: [Emergencia ▼]   │ ← AQUÍ SE USA
│ Veterinario: [Dr. García ▼]         │
│ Observaciones: [____________]        │
└─────────────────────────────────────┘
```

#### 🔮 **HISTORIAL MÉDICO** (Futuro)
- Para registrar cada consulta en el historial
- Ver estadísticas: "Max ha tenido 5 consultas generales y 2 emergencias"

---

## ⚠️ 2. GRAVEDADES
**`tbGravedades`** - Nivel de gravedad de una condición médica

### 📍 Pantallas que lo usan:

#### ✅ **DIAGNÓSTICOS / CONSULTAS**
- **Pantalla:** Detalle de Consulta Médica
- **Campo sugerido:** `grav_Id` (FK a tbGravedades)
- **Uso:** Al diagnosticar un problema, el veterinario indica la gravedad:
  - Leve (resfriado, rasguño)
  - Moderada (infección leve, vómito)
  - Grave (fracturas, infección severa)
  - Crítica (emergencia vital)

**Ejemplo de uso:**
```
┌──────────────────────────────────────────┐
│ Consulta Médica - Max                    │
├──────────────────────────────────────────┤
│ Diagnóstico: Infección respiratoria      │
│ Gravedad: [Moderada ▼]                   │ ← AQUÍ SE USA
│                                           │
│ [Leve] [Moderada] [Grave] [Crítica]      │
└──────────────────────────────────────────┘
```

#### ✅ **ALERTAS DE SALUD**
- Sistema puede mostrar alertas según gravedad
- Dashboard muestra: "3 mascotas en estado GRAVE"
- Priorización de atención médica

#### ✅ **REPORTES**
- Estadísticas de casos por gravedad
- "Este mes: 10 Leves, 5 Moderados, 2 Graves"

---

## 💊 3. TIPOS DE MEDICAMENTO
**`tbTiposMedicamento`** - Categoría del medicamento

### 📍 Pantallas que lo usan:

#### ✅ **RECETAS MÉDICAS** (Tabla nueva sugerida: tbRecetas)
- **Pantalla:** Prescripción de Medicamentos
- **Campo sugerido:** `tipoMed_Id` (FK)
- **Uso:** Al recetar medicamento, se clasifica:
  - Antibiótico
  - Antiparasitario
  - Antiinflamatorio
  - Analgésico
  - Vitaminas
  - Vacuna

**Ejemplo de uso:**
```
┌─────────────────────────────────────────────┐
│ Receta Médica - Max                         │
├─────────────────────────────────────────────┤
│ Medicamento: Amoxicilina 500mg              │
│ Tipo: [Antibiótico ▼]                       │ ← AQUÍ SE USA
│ Vía: [Oral ▼]                               │
│ Dosis: 1 tableta cada 12 horas             │
│ Duración: 7 días                            │
└─────────────────────────────────────────────┘
```

#### ✅ **INVENTARIO DE MEDICAMENTOS**
- Clasificar medicamentos en bodega por tipo
- Filtrar: "Mostrar solo Antibióticos"
- Alertas: "Stock bajo en Antiparasitarios"

#### ✅ **CONTROL DE TRATAMIENTOS**
- Seguimiento de medicamentos administrados
- Historial: "Ha recibido 3 antibióticos este año"

---

## 💉 4. VÍAS DE ADMINISTRACIÓN
**`tbViasAdministracion`** - Cómo se administra el medicamento

### 📍 Pantallas que lo usan:

#### ✅ **RECETAS / TRATAMIENTOS**
- **Pantalla:** Prescripción de Medicamentos
- **Campo sugerido:** `viaAdmin_Id` (FK)
- **Uso:** Indicar cómo dar el medicamento:
  - Oral (pastillas, jarabe)
  - Inyectable IM (intramuscular)
  - Inyectable IV (intravenosa)
  - Tópica (cremas, gotas)
  - Subcutánea

**Ejemplo de uso:**
```
┌─────────────────────────────────────────────┐
│ Administración de Medicamento               │
├─────────────────────────────────────────────┤
│ Medicamento: Antiparasitario               │
│ Vía: [Inyectable (IM) ▼]                   │ ← AQUÍ SE USA
│ Zona: Músculo del muslo trasero            │
│ Fecha aplicación: [01/11/2025]             │
└─────────────────────────────────────────────┘
```

#### ✅ **REGISTRO DE ENFERMERÍA**
- Al aplicar tratamiento, enfermero registra vía usada
- Control de vacunación: qué vía se utilizó

#### ✅ **HISTORIAL DE ADMINISTRACIÓN**
- Ver todas las aplicaciones por vía
- "Max ha recibido 10 inyecciones IM este año"

---

## 🐛 5. TIPOS DE PARÁSITO
**`tbTiposParasito`** - Tipo de parásito detectado (con categoría)

### 📍 Pantallas que lo usan:

#### ✅ **CONTROL ANTIPARASITARIO**
- **Pantalla:** Desparasitación / Tratamiento Antiparasitario
- **Campo sugerido:** `tipoPar_Id` (FK)
- **Uso:** Registrar desparasitación o infestación:
  - **Externos:** Pulgas, Garrapatas, Ácaros
  - **Internos:** Lombrices, Giardia, Tenias

**Ejemplo de uso:**
```
┌─────────────────────────────────────────────┐
│ Control Antiparasitario - Max               │
├─────────────────────────────────────────────┤
│ Tipo detectado: [Pulgas ▼]                  │ ← AQUÍ SE USA
│ Categoría: EXTERNO                          │
│ Gravedad: [Moderada ▼]                      │
│ Tratamiento: Pipeta antiparasitaria        │
│ Próxima dosis: [01/12/2025]                │
└─────────────────────────────────────────────┘
```

#### ✅ **CALENDARIO DE DESPARASITACIÓN**
- Programar desparasitaciones según tipo
- "Desparasitación interna cada 3 meses"
- "Desparasitación externa mensual"

#### ✅ **REPORTES EPIDEMIOLÓGICOS**
- "5 casos de pulgas este mes en el refugio"
- Alertas de brotes parasitarios

---

## ✂️ 6. TIPOS DE ESTERILIZACIÓN
**`tbTiposEsterilizacion`** - Tipo de procedimiento de esterilización (con sexo)

### 📍 Pantallas que lo usan:

#### ✅ **HISTORIAL MÉDICO** (Mejorado)
- **Pantalla:** Ficha Médica de Mascota
- **Campo sugerido:** Cambiar `cita_Esterilizacion` (bool) → `tipoEst_Id` (FK)
- **Uso actual:** Solo dice SI/NO esterilizado
- **Uso mejorado:** Dice QUÉ tipo de esterilización:
  - Castración (Macho)
  - Ovariohisterectomía (Hembra)
  - Vasectomía (Macho)

**ANTES (actual):**
```
┌─────────────────────────────────────┐
│ Ficha Médica - Max                  │
├─────────────────────────────────────┤
│ ☑ Esterilizado                      │
└─────────────────────────────────────┘
```

**DESPUÉS (mejorado):**
```
┌─────────────────────────────────────────┐
│ Ficha Médica - Max                      │
├─────────────────────────────────────────┤
│ Esterilizado: [Castración ▼]            │ ← AQUÍ SE USA
│ Sexo aplicable: Macho                   │
│ Fecha cirugía: [15/05/2024]             │
│ Veterinario: Dr. García                 │
└─────────────────────────────────────────┘
```

#### ✅ **PROGRAMACIÓN DE CIRUGÍAS**
- Agenda de esterilizaciones
- Planificar recursos según tipo de cirugía
- "Esta semana: 3 castraciones y 2 ovariohisterectomías"

#### ✅ **ESTADÍSTICAS**
- "Total de esterilizaciones este año: 50"
- Desglose por tipo y sexo
